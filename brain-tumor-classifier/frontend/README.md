# Frontend — Brain Tumor Classifier

Site web (React + TypeScript + Vite + Tailwind CSS + shadcn/ui) du projet.

## Lancer en local

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # vérification TypeScript + build de production
npm run lint
```

Le site appellera l'API (`../api`) à partir de l'étape 8b.
